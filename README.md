# 🌿 রূপসী বাংলা (Ruposhi Bangla)

**প্রকৃতি, জীববৈচিত্র্য ও প্রকৃতিপ্রেমীদের ডিজিটাল মিলনমেলা**

বাংলাদেশের **সব প্রাণী ও উদ্ভিদ** — পাখি থেকে মাছ, সরীসৃপ থেকে কীটপতঙ্গ, গাছ-লতা থেকে ছত্রাক ও অণুজীব — সব এক জ্ঞানভান্ডারে; সাথে নদী-বন-পাহাড়, গ্রামবাংলা, কবির চোখে প্রকৃতি, সংবাদ-সংরক্ষণ, কমিউনিটি ফিড-রিলস এবং নিজস্ব এআই সহচর।

> নিয়ন্ত্রক দলিল: [`MASTER-PROMPT.md`](./MASTER-PROMPT.md) — প্ল্যাটফর্মের প্রতিটি বিধান সেখানে ধারা অনুযায়ী লিপিবদ্ধ।
> সংখ্যাগুলো হাতে লেখা নয় — `npm run stats` চালালে কোডের সিড থেকে সরাসরি গণনা হয়ে আসে।

## 🛠 টেক স্ট্যাক

- **Next.js 15** (App Router, TypeScript, Server Components, Route Handlers)
- **Tailwind CSS** — কাস্টম `forest`/`earth` প্যালেট, বাংলা ফন্ট (Hind Siliguri)
- **Neon Postgres** (`@neondatabase/serverless`) — `DATABASE_URL` থাকলে; না থাকলে লোকাল `.data/db.json`
- **Cloudflare R2** (S3-compatible) — `R2_*` সেট থাকলে; না থাকলে `public/uploads`
- **নিজস্ব এআই ইঞ্জিন** — লোকাল রিট্রিভাল (অফলাইনে কাজ করে), চাইলে OpenAI/OpenRouter/Gemini যুক্ত করা যায়
- **নিরাপত্তা** — HMAC-সাইন করা সেশন কুকি, bcrypt-সদৃশ পাসওয়ার্ড হ্যাশ, zod যাচাই, **রেট লিমিটিং** (ঐচ্ছিক Upstash Redis কেন্দ্রীয় স্টোর + ইন-মেমোরি ফলব্যাক)
- **পরীক্ষা** — **Vitest** ইউনিট টেস্ট + Node-ভিত্তিক ৪টি সিড/মিডিয়া চুক্তি-পরীক্ষা; CI-তে lint, tsc, test, build
- **SEO** — বাংলা মেটাডেটা, JSON-LD, `sitemap.xml`, `robots.txt`, OG ইমেজ

## 🚀 লোকালে চালান

```bash
npm install
cp .env.example .env.local   # ঐচ্ছিক — ছাড়াও চলবে
npm run dev                  # http://localhost:3000
npm run test:unit            # Vitest — কভারেজের হিসাব, রেট-লিমিট, ক্যাটাগরি
npm test                     # ইউনিট + সিড/মিডিয়া চুক্তি — সব
npm run lint                 # ESLint (Next.js নিয়ম)
npm run stats                # ডকুমেন্টেশনের জন্য প্রকৃত সংখ্যা (মার্কডাউন)
npm run audit:images         # কোন প্রজাতির ছবি আদৌ দেখা যাচ্ছে — রিপোর্ট
npm run audit:images -- --check   # দূরবর্তী (কমন্স) লিংকও যাচাই (ইন্টারনেট দরকার)
```

প্রথমবারেই সিড ডেটা (প্রজাতি, **রূপসী বাংলা** অফিসিয়াল চ্যানেল, সিড পোস্ট ও খবর) বসে যায়।
**প্রথম যে অ্যাকাউন্ট খুলবেন সেটিই অ্যাডমিন** → `/admin`।

```bash
npm run build && npm start   # প্রোডাকশন বিল্ড
```

## 📷 মিডিয়া ক্রেডিট ও লাইসেন্স

`public/seed`-এ থাকা ছবিগুলোর উৎস ও লাইসেন্স **প্রতি-ফাইল যাচাই করা বাকি** এবং `/credits` পেজে তা স্পষ্টভাবে দেখানো হয়েছে — কল্পিত ক্রেডিট কোথাও নেই। `public/illustrations`-এর সাধারণ দৃশ্যগুলো প্রকল্পের নিজস্ব (AI-সহায়তায় তৈরি) — এগুলো কোনো নির্দিষ্ট স্থানের বাস্তব ছবি নয়, সে কথা প্রজাতির পাতা ও ক্রেডিটে লেখা। প্রোডাকশনে যাওয়ার আগে বাকি ৬৬৯টি ফাইলের উৎস/লেখক/লাইসেন্স যোগ করতে হবে অথবা নিজস্ব বা লাইসেন্সকৃত ছবি দিয়ে বদলাতে হবে।

## ⚠️ যা এখনো অসম্পূর্ণ (সৎ তালিকা)

1. **ছবি:** ১৭৫৯টির মধ্যে ১৭৫৬টিতে ছবি আছে (লোকাল ৬৯১ + কমন্স-রেফারেন্স ১০৬৫; ১০৬৩টি অনন্য দূরবর্তী URL, ২টি লেগ্যাসি শেয়ার্ড URL); ৩টি বাদুড়ের কোনো মুক্ত-লাইসেন্স ছবি নেই — `data/seed/image-gaps.ts`-এ কারণসহ নথিভুক্ত। ৬৬৯টি ছবির লেখক/সুনির্দিষ্ট লাইসেন্স এখনো যাচাই বাকি (`verified:false`)।
2. **তথ্যের ফাঁক:** ৬৬টি প্রাণী-রেকর্ডে (মূলত ৬০টি স্তন্যপায়ী) “অন্য/স্থানীয় নাম” নেই; ৩৭টি পাহাড়/বন-রেকর্ডে উচ্চতা/আয়তন নেই। কভারেজ ড্যাশবোর্ডে এগুলো ক্ষেত্র-ধরে দেখানো হয় — অনুমান করে ভরাট করা হয় না।
3. **১৮টি জীবগোষ্ঠীর পূর্ণ তালিকা:** মাকড়সা, মলাস্কা, ক্রাস্টেসিয়ান, লাইকেন ও বীজবিহীন উদ্ভিদ (মস/ফার্ন) — এদের জন্য কয়েকটি করে রেকর্ড আছে, পূর্ণ তালিকা নয়। বাংলাদেশের হাজারো প্রজাতির বিপরীতে ১৭৫৯ একটি ধাপ; ধাপে ধাপে বাড়ানোর কাঠামো (`CSV/JSON আমদানি`) তৈরি আছে।
4. **এআই:** লোকাল রিট্রিভাল ইঞ্জিন; বাংলা ভাষা-মডেল নয়। ভিশন-ভিত্তিক শনাক্তকরণ রঙ-মিলে সীমিত।
5. **রেট লিমিটিং:** `UPSTASH_REDIS_REST_*` দিলে কেন্দ্রীয়; না দিলে ইন-মেমোরি — একাধিক ইনস্ট্যান্সে হিসাব আলাদা হয়ে যেতে পারে।
6. **রিলস:** সার্ভার-পাশে দৈর্ঘ্য যাচাইয়ের জন্য ffmpeg/মিডিয়া-প্রসেসিং এখনো নেই (ধরন ও সাইজ যাচাই আছে)।
7. **নীল টিক অনুমোদন প্রক্রিয়া:** অ্যাডমিন দেয় ও অডিট লগে পড়ে; আবেদন-ফর্ম ও ডকুমেন্ট যাচাইয়ের ওয়ার্কফ্লো বাকি।
