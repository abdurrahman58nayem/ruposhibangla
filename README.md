# প্রকৃতি বাংলা (Prakriti Bangla)

বাংলাদেশের প্রাণী, পাখি, উদ্ভিদ, গ্রাম-প্রকৃতি ও মানুষের জন্য তৈরি একটি আধুনিক, মোবাইল-ফার্স্ট ওয়েব অ্যাপ্লিকেশন —
তথ্যভাণ্ডার + সোশ্যাল ফিড + নিজস্ব এআই সহচর + অ্যাডমিন প্যানেল, সব একসাথে।

> মূল চ্যানেল: **রূপসী বাংলা** (যাচাইকৃত / ব্লু টিক)

## ✨ যা যা আছে

| মডিউল | বিবরণ |
|---|---|
| **প্রজাতির তথ্যভাণ্ডার** | বাংলাদেশের ৮০+ প্রাণী ও উদ্ভিদ — বাংলা/ইংরেজি/বৈজ্ঞানিক নাম, বিভাগ, বাসস্থান, খাদ্য, আকার, মৌসুম, কোথায় দেখা যায়, IUCN সংরক্ষণ অবস্থা, তথ্যসূত্র |
| **কবির চোখে** | রবীন্দ্রনাথ, নজরুল, জীবনানন্দ, জসীম উদ্‌দীন—কবিরা প্রকৃতিকে কীভাবে দেখেছেন, প্রজাতিভিত্তিক আর্কাইভ |
| **গ্রামবাংলা** | ধানখেত, মাটির ঘর, নদীর নৌকো, হাট, কৃষক ও জেলের দৈনন্দিন জীবন |
| **প্রকৃতির খবর** | অ্যাডমিন প্যানেল থেকে প্রকাশযোগ্য নিউজ, পিন ও হেডার নোটিশ |
| **শেয়ার ও সোশ্যাল** | অ্যাকাউন্ট ছাড়াই নাম দিয়ে ছবি/ভিডিও/লেখা শেয়ার, লাইক, কমেন্ট, ফলো, প্রোফাইল |
| **ব্লু টিক** | অ্যাডমিন যাকে খুশি যাচাইকৃত পার্টনার (verified) করতে পারবেন |
| **প্রকৃতি সহচর (এআই)** | সাইটের নিজস্ব তথ্য থেকে উত্তর দেয় — টেক্সট ও ছবি (রঙ-ভিত্তিক মিল) দুটোতেই |
| **জেনো** | দর্শকদের পাঠানো তথ্য/ভুল সংশোধন — অ্যাডমিন প্যানেলে মডারেশন |
| **অ্যাডমিন প্যানেল** | প্রজাতি CRUD, খবর, পোস্ট মডারেশন, ব্যবহারকারী ও ব্লু টিক, জেনো, সাইট সেটিংস, সোশ্যাল লিংক, মিডিয়া আপলোড |

## 🛠 টেক স্ট্যাক

- **Next.js 15** (App Router, TypeScript, Server Components)
- **Tailwind CSS** — কাস্টম forest/earth প্যালেট, বাংলা ফন্ট (Hind Siliguri)
- **Neon Postgres** (`@neondatabase/serverless`) — `DATABASE_URL` থাকলে; না থাকলে লোকাল JSON স্টোর
- **Cloudflare R2** (S3-compatible) — `R2_*` সেট থাকলে; না থাকলে `public/uploads`
- **নিজস্ব এআই ইঞ্জিন** — লোকাল রিট্রিভাল (অফলাইন), চাইলে OpenAI/OpenRouter/Gemini মডেল যুক্ত করা যায়
- **SEO** — মেটাডেটা, JSON-LD, sitemap.xml, robots.txt, OG image

## 🚀 লোকালে চালান

```bash
npm install
cp .env.example .env.local   # ঐচ্ছিক — ছাড়াও চলবে
npm run dev                  # http://localhost:3000
```

প্রথমবারেই `.data/db.json`-এ বাংলাদেশের প্রজাতি, রূপসী বাংলা চ্যানেল, ১৮টি সিড পোস্ট ও ৩টি খবর বসে যায়।

**প্রথম অ্যাকাউন্টই অ্যাডমিন** — `/register` থেকে অ্যাকাউন্ট খুললে সেটি `admin` রোল পাবে, তারপর `/admin`।

## 🗄 Neon + R2 কনফিগারেশন

`.env.local` (বা Vercel Environment Variables):

```env
DATABASE_URL="postgresql://user:pass@ep-xxx.region.aws.neon.tech/prakriti_bangla?sslmode=require"
R2_ACCOUNT_ID="..."
R2_ACCESS_KEY_ID="..."
R2_SECRET_ACCESS_KEY="..."
R2_BUCKET_NAME="prakriti-bangla"
R2_PUBLIC_URL="https://pub-xxxx.r2.dev"
AUTH_SECRET="একটি-লম্বা-র‍্যান্ডম-স্ট্রিং"
NEXT_PUBLIC_SITE_URL="https://prakritibangla.org"
```

এরপর অ্যাডমিন প্যানেল → **ড্যাশবোর্ড** → “টেবিল তৈরি” → “প্রজাতির তথ্য বসানো” বাটনে ক্লিক করলেই Neon-এ সব টেবিল ও তথ্য চলে যাবে।
বিস্তারিত ধাপে ধাপে গাইড: [`DEPLOYMENT.md`](./DEPLOYMENT.md)

## 📁 গুরুত্বপূর্ণ ফোল্ডার

```
app/           Next.js App Router পেজ ও API
  api/         posts, species, news, ai, upload, auth, follow, jeno, settings, admin
  admin/       অ্যাডমিন প্যানেল (রোল-গার্ডেড)
components/    UI কম্পোনেন্ট (Feed, PostCard, SpeciesCard, AiChat, admin/*)
lib/           repo (Neon/JSON), ai (retrieval+answer), storage (R2/local), auth, utils
data/seed/     বাংলাদেশের প্রজাতি, চ্যানেল, সিড পোস্ট ও খবর
public/seed/   সিড ছবি (প্রাণী, উদ্ভিদ, গ্রামবাংলা)
db/schema.sql  Neon-এর টেবিল স্কিমা
```
