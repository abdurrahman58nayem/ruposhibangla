## 🛠 টেক স্ট্যাক

- **Next.js 15** (App Router, TypeScript, Server Components, Route Handlers)
- **Tailwind CSS** — কাস্টম `forest`/`earth` প্যালেট, বাংলা ফন্ট (Hind Siliguri)
- **Neon Postgres** (`@neondatabase/serverless`) — `DATABASE_URL` থাকলে; না থাকলে লোকাল `.data/db.json`
- **Cloudflare R2** (S3-compatible) — `R2_*` সেট থাকলে; না থাকলে `public/uploads`
- **নিজস্ব এআই ইঞ্জিন** — লোকাল রিট্রিভাল (অফলাইনে কাজ করে), চাইলে OpenAI/OpenRouter/Gemini যুক্ত করা যায়
- **নিরাপত্তা** — HMAC-সাইন করা সেশন কুকি, bcrypt-সদৃশ পাসওয়ার্ড হ্যাশ, zod যাচাই, **ইন-মেমোরি রেট লিমিটিং**
- **SEO** — বাংলা মেটাডেটা, JSON-LD, `sitemap.xml`, `robots.txt`, OG ইমেজ

## 🚀 লোকালে চালান

```bash
npm install
cp .env.example .env.local   # ঐচ্ছিক — ছাড়াও চলবে
```

```bash
npm run build && npm start   # প্রোডাকশন বিল্ড
```

## 📷 মিডিয়া ক্রেডিট ও লাইসেন্স

`public/seed`-এ থাকা ছবিগুলো ডেভেলপমেন্টের স্থানধারক — এদের উৎস ও লাইসেন্স **যাচাই করা বাকি** এবং `/credits` পেজে তা স্পষ্টভাবে দেখানো হয়েছে। প্রোডাকশনে যাওয়ার আগে প্রতিটি ফাইলের উৎস/লেখক/লাইসেন্স যোগ করতে হবে অথবা নিজস্ব বা লাইসেন্সকৃত ছবি দিয়ে বদলাতে হবে। ভুল ক্রেডিট কোনোভাবেই দেওয়া যাবে না।

## ⚠️ যা এখনো অসম্পূর্ণ (সৎ তালিকা)

1. **ছবি:** ২০২টি রেকর্ডের ১১৮টিতে ছবি আছে, ৮৪টিতে নেই (প্রধানত সরীসৃপ, কীট, পাখি, স্তন্যপায়ী, অণুজীব, সাহিত্য)। নতুন যোগ করা ৭৭টি ছবি উইকিমিডিয়া কমন্স/পেক্সেলস থেকে নেওয়া — প্রতিটির উৎস-লিংক `/credits`-এ আছে, তবে লেখকের নাম ও সুনির্দিষ্ট লাইসেন্স এখনো যাচাই বাকি (`verified:false`)। আমরা কোনো ছবি চোখে দেখে যাচাই করতে পারিনি — প্রজাতি শনাক্তকরণ উৎস-পাতার তথ্যের ওপর ভিত্তিক, এবং ৯টি ছবি রেজোলিউশনে ছোট (`lowRes`), ৫টির প্রজাতি শনাক্তকরণ নিশ্চিত নয় (`confidence:low/medium`)।
2. **তথ্যের অবস্থা:** ২০২টি রেকর্ডের মধ্যে মাত্র ৩টি `verified` — বাকিগুলো `partial`; পূর্ণাঙ্গ ক্ষেত্র (প্রজনন, আচরণ, হুমকি, সংরক্ষণ) ও দ্বিতীয় সূত্র যুক্ত করা বাকি।
3. **১৮টি জীবগোষ্ঠীর পূর্ণ তালিকা:** মাকড়সা, মলাস্কা, ক্রাস্টেসিয়ান, লাইকেন ও বীজবিহীন উদ্ভিদ (মস/ফার্ন) — এদের জন্য কয়েকটি করে রেকর্ড আছে, পূর্ণ তালিকা নয়। বাংলাদেশের হাজারো প্রজাতির বিপরীতে ২০২ একটি সূচনা মাত্র; ধাপে ধাপে বাড়ানোর কাঠামো (`CSV/JSON আমদানি`) তৈরি আছে।
4. **এআই:** লোকাল রিট্রিভাল ইঞ্জিন; বাংলা ভাষা-মডেল নয় — উন্নত এআই যুক্ত করলে আরও ভালো উত্তর আসবে। ভিশন-ভিত্তিক শনাক্তকরণ রঙ-মিলে সীমিত।
5. **রেট লিমিটিং:** ইন-মেমোরি — একাধিক ইনস্ট্যান্সে ভাগ হয় না; বড় স্কেলে কেন্দ্রীয় স্টোর (Redis/Upstash) দরকার।
6. **রিলস:** সার্ভার-পাশে দৈর্ঘ্য যাচাইয়ের জন্য ffmpeg/মিডিয়া-প্রসেসিং এখনো নেই (ধরন ও সাইজ যাচাই আছে)।
7. **নীল টিক অনুমোদন প্রক্রিয়া:** অ্যাডমিন দেয় ও অডিট লগে পড়ে; কিন্তু আবেদন-ফর্ম ও ডকুমেন্ট যাচাইয়ের ওয়ার্কফ্লো বাকি।
8. **ডেটা ডাউনলোড/মুছার অনুরোধ:** এপিআই ও ফর্ম আছে; ব্যাকগ্রাউন্ড জব ও ইমেইল বিজ্ঞপ্তি বাকি।
9. **পরীক্ষা:** স্বয়ংক্রিয় ইউনিট/ইন্টিগ্রেশন টেস্ট নেই — `docs/TESTING.md`-এ ম্যানুয়াল চেকলিস্ট আছে।
10. **বাংলা বানান-ভেদ সার্চ:** মৌলিক সাধারণীকরণ আছে; পূর্ণ ফোনেটিক ম্যাপিং বাকি।
