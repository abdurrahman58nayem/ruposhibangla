## ১. মাপ (৪কে, `SCALE=2`, ক্যানভাস ২১৬০×৩৮৪০)

| উপাদান | কী-ফন্ট | সাইজ |
|---|---|---|
| চিপ | `sans-semi` | `38*SCALE` |
| স্ট্যাক (হিরো ২ লাইন) | `serif-bold` | `88*SCALE` |
| ভ্যালু (মান / বৈজ্ঞানিক নাম) | `serif-bold` | `112*SCALE` |
| লেবেল (ভ্যালুর উপরে ছোট) | `sans-semi` | `40*SCALE` |
| লিস্ট হেড | `sans-semi` | `46*SCALE` |
| লিস্ট সাব | `sans-semi` | `34*SCALE` |
| পিল | `sans-semi` | `40*SCALE` |

- **সেফ এরিয়া:** বাঁ `MINX = 0.075W`, ডান সীমা `MAXW = 0.845W`।
- **অটো-ফিট বাধ্যতামূলক:** `fit_px()` / `stack_px()`। বাংলা লাইনের প্রস্থ আন্দাজ করা যায় না —
  মেপে নামাতে হবে, নইলে `১৮–২০ সেন্টিমিটার` ডান পাশ কেটে যায়।
- **`align="mid"` রো ১০৮০ ক্যানভাসে আঁকা হয়**, তারপর `resize((W,H))`। ৪কে-তে সোজা
  `T.flow` দিলে লেখা দুই গুণ চওড়া হয়ে কেটে যায়।

## ২. প্যানেল — এক গ্রুপ, তীক্ষ্ণ, ~৮৮%

```
PANEL_FILL   = (17, 23, 21)
PANEL_A      = 224        # ৮৮%
PANEL_RADIUS = 26 * SCALE # ফ্রেম-প্রস্থের ~৩.৫%
feather      = 1.6 * SCALE  # শুধু সিঁড়ি-কিনারা মসৃণ করতে
pad          = 52 × 40 (SCALE-গুণ)
```

- **প্যানেল কখন বসবে:** `_patch_bright(box, thr=150, busy_thr=0.11)` — প্যাচের ৮৮তম
  পার্সেন্টাইল লুমা ≥ ১৫০ **অথবা** গড় উল্লম্ব গ্রেডিয়েন্ট ≥ ১১%। অর্থাৎ শুকনো ঘাস,
  কাদা, জল — সবখানে প্যানেল; শুধু সত্যিই গাঢ় ও শান্ত জমিনে প্যানেল ছাড়া।
- **ঠিক কী কী প্যানেল চায়:**

| স্টাইল | প্যানেল |
|---|---|
| `label` + `value` (জোড়া) | হ্যাঁ — একটাই, দুটো লাইন ঢেকে |
| `list` রো (২–৩টা একসাথে) | হ্যাঁ — একটাই, পুরো গ্রুপ |
| `stack` (হিরো) | শুধু জমিন উজ্জ্বল/busy হলে |
| `chip`, `pill`, `pills` | **কখনো না** (ওদের নিজের ক্যাপসুল আছে) |

- **ফ্রেম-বাউন্ড:** গ্রুপের প্যানেল `H - 54*SCALE` ছাড়ালে পুরো গ্রুপ **সর্বোচ্চ ১২০px**
  উপরে তোলা হয় — প্যানেল কাটা যাবে না।
- **চিপ-ক্লিয়ারেন্স:** চিপের নিচের প্রান্ত প্যানেলের উপরে থাকলে ততটুকু বাদ যায়;
  কিন্তু **শুধু তখনই** যখন `chip_bot < min(b[1] for b in geom)`। এই গার্ড ছাড়া পুরো
  গ্রুপ-বক্স একটা সরু স্ট্রিপে কলাপ্স করেছিল।

## ৩. রঙ — ভ্যারিয়েশন বাধ্যতামূলক

```
C_CREAM (255,252,245)  C_GOLD (250,206,132)  C_MINT (196,232,208)
C_SKY   (186,214,232)  C_SAND (238,214,186)  C_CORAL(255,156,120)
SUB_INK (150,178,168)  # লিস্টের সাব-লাইন
```

- **হিরো স্ট্যাক:** লাইন ১ = ক্রিম/সাদা, লাইন ২ = গোল্ড। এক লাইনে এক রঙ নয়।
- **লিস্ট:** প্রতিটা রো-র হেড ও বার নিজের অ্যাকসেন্ট পায় (সাদা/মিন্ট/স্কাই/কোরাল) —
  পরপর দুই রো একই রঙ নয়। সাব-লাইন সবসময় `SUB_INK`।
- **পিল:** `PILLS = [GOLD, MINT, SKY, CREAM]` ক্রমে ঘোরে; বর্ডার ও লেখা একই অ্যাকসেন্ট।
- **চিপ:** ডট + লেখা অ্যাকসেন্টে, ফিল প্রায়-কালো স্বচ্ছ।
- **উজ্জ্বল জমিনে ইঙ্ক গাঢ় করা নিষিদ্ধ** — গোল্ড/কোরাল ধূসর হয়ে যায়।

## ৪. লেআউট আর বিট

```python
BEATS = {"s01": [(0, "chip", "…", C_MINT, 430, "mid"),
                 (0, "stack", "লাইন১|লাইন২", C_GOLD, 545, "mid"),
                 (1, "list",  "হেড|সাব", C_WHITE, 2020, "left"),
                 (2, "label", "লেবেল|মান", C_GOLD, -1, "left")],
         …}
```
- প্রথম সংখ্যা = বিট ইনডেক্স (কখন আসবে), শেষ `y` = টপ, `-1` = আগের রো-র ঠিক নিচে।
- চিপ উপরে (y≈৪০০–৪৩০), নিচের লিস্ট-ব্লক y≈২০০০–২৯০০।
- ক্লোজ-আপ সিনে (পাখির মাথা বড়) টেক্সট নিচে নামাতে হবে — মুখ/চোখ/ঠোঁটে কিছু বসবে না।

## ৫. উচ্চতা-মাপ — যেখানে দুবার বাগ হয়েছিল

- **`row_bottom(style, txt, y, align)` authoritative** — এটা প্রতিটা ড্র-ব্রাঞ্চের হুবহু মিল,
  এবং **অবсолют `y`** ফেরত দেয় (`y_row + row_bottom(...)` নয় — তাহলে `y` দুইবার যোগ হয়)।
- `row_bottom` **`_row_geom` কল করবে না** — রিকার্সন / `TypeError: 'NoneType' object is not iterable`।
  প্রতিটা স্টাইলের নিজের শাখা থাকবে, আর খালি লেবেলের (`|` ছাড়া) গার্ড থাকবে।
- `_row_geom`-এ `list`-এর নিজের শাখা থাকবে — নাহলে সাব-লাইন প্যানেলের বাইরে পড়ে।
- `_row_geom`-এর চিপ শাখা **ড্র-ল্যাম্বডা ফেরত দেবে**; `(None,None,False)` দিলে সব চিপ চুপচাপ হারায়।
