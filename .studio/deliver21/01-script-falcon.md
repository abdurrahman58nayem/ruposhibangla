# আমুর শাহিন — ভয়েস স্ক্রিপ্ট (রিল ০১৭)

> তথ্য: রূপসী বাংলা — আমুর শাহিন / Amur Falcon (**Falco amurensis**), গোত্র Falconidae, IUCN **LC**।
> দৈর্ঘ্য ২৬–৩০ সেমি, ডানা ৬৩–৭১ সেমি, ওজন ~৯৭–১৮৮ গ্রাম। পুরুষ স্লেট-ধূসর ডানা + লালচে পেট + কমলা-লাল পা; স্ত্রী বড়, বুকেও ডোরা।
> বাংলাদেশে **শীতে পথচলতি অতিথি** (অক্টো–ডিসে)। প্রজনন সাইবেরিয়া-উত্তর চীনে, মে–জুলাই; পুরোনো বাসা ব্যবহার, ২–৬ ডিম।
