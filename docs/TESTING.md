# 🧪 পরীক্ষা ও গ্রহণযোগ্যতা — রূপসী বাংলা

মাস্টার প্রম্পটের **§২৫-এর ২৭টি গ্রহণযোগ্যতা পরীক্ষা** এখানে ধাপে ধাপে লেখা আছে। প্রতিটি পরীক্ষায় “কীভাবে যাচাই করবেন” ও প্রত্যাশিত ফল দেওয়া হয়েছে।

> স্বয়ংক্রিয় স্তর দুটি: **Vitest ইউনিট টেস্ট** (`npm run test:unit`) এবং **সিড/মিডিয়া চুক্তি-পরীক্ষা**
> (`npm run test:contract`)। নিচের ২৭টি ধাপ ব্রাউজার-ভিত্তিক ম্যানুয়াল QA চেকলিস্ট — e2e অটোমেশন এখনো বাকি।

---

## ক) ভিত্তি ও নেভিগেশন

**১. সাইট লোড ও বাংলা রেন্ডারিং**
- `/` খুলুন → বাংলা লেখা ঠিকভাবে দেখায়, ফন্ট লোড হয়, কোনো টেক্সট কাটা যায় না।

**২. ১৭টি ক্যাটাগরি**
- হোমপেজের ক্যাটাগরি রেল অনুভূমিক স্ক্রল করে; `/categories`-এ ১৭টিই আছে; যেকোনোটিতে ক্লিক করলে `/gyan?group=<id>` বা `/feed?group=<id>` খোলে।
- **প্রাণীজগৎ** একটি ছাতা-ক্যাটাগরি — এতে সব প্রাণী (১২০২টি) দেখা যায়, কিন্তু কভারেজের মোটে এটি আলাদা গোনা হয় না।

**৩. নিচের নেভিগেশনে ঠিক ছয়টি আইটেম**
- মোবাইলে নিচে: জ্ঞানভান্ডার · ফিড · রিলস · প্রোফাইল · AI · সেটিংস; বর্তমান পেজ হাইলাইট থাকে; নিচে নিরাপদ প্যাডিং (কনটেন্ট ঢাকা পড়ে না)।

## খ) জ্ঞানভান্ডার (§৫)

**৪. বহুভাষিক খোঁজা**
- `/search?q=ইলিশ` → ইলিশ; `q=Tenualosa` → একই রেকর্ড; `q=হিলসা` (স্থানীয় নাম) → মেলে।
- বানান-ভেদ: `দোয়েল` ও `দোয়েল` দুটোতেই একই ফল।

**৫. প্রজাতির পাতায় সব ক্ষেত্র**
- `/prani/doyel` → বাংলা/ইংরেজি/বৈজ্ঞানিক নাম, বিভাগ, বাসস্থান, খাদ্য, আকার, মৌসুম, শনাক্তকরণ, সারাংশ, তথ্যসূত্র, গ্যালারি, সংশ্লিষ্ট পোস্ট।

**৬. তথ্যের অবস্থার ব্যাজ**
- প্রজাতির পাতায় “তথ্য: …” ব্যাজ; `verified`=সবুজ, `partial`=হলুদ, `identity_uncertain`=লাল, `needs_correction`=কমলা।

**৭. অসম্পূর্ণ রেকর্ডে ব্যানার**
- যে রেকর্ড `verified` নয়, সেখানে “এই রেকর্ডের তথ্য এখনো অসম্পূর্ণ”Panel দেখা যায়।

## গ) ফিড (§৬)

**৮. সাতটি ফিড ফিল্টার**
- `/feed` → সবার জন্য/নতুন/জনপ্রিয়/অনুসরণ/ছবি/ভিডিও(রিলস)/ক্যাটাগরি।
- `জনপ্রিয়` → পছন্দ অনুযায়ী সাজানো; `অনুসরণ` (লগইন ছাড়া) → লগইন করতে বলে।

**৯. পোস্ট কার্ডে সব উপাদান**
- অবতার, নাম, @ইউজারনেম, নীল টিক (কেবল যাচাইকৃত), সময়, মিডিয়া, ক্যাপশন, ক্যাটাগরি চিপ, প্রজাতির লিংক, পছন্দ, মন্তব্য, শেয়ার, রিপোর্ট।

**১০. অতিথি নাম দিয়ে শেয়ার**
- লগইন ছাড়াই `/share` → নাম + ছবি → জমা। অতিথির পোস্ট `pending` হয় (পর্যালোচনার পর প্রকাশ), লগইনকৃত/যাচাইকৃত অংশীদারের পোস্ট সাথে সাথে `approved`।

## ঘ) রিলস (§৭)

**১১. প্লেয়ার**
- `/reels` → ফুল-স্ক্রিন ভার্টিক্যাল, সোয়াইপ করলে পরেরটি, ট্যাপে পজ/প্লে, মিউট/আনমিউট, লেখক ও প্রজাতির লিংক, রিপোর্ট।

**১২. ভিডিও যাচাই**
- `/api/upload`-এ ভিডিও ছাড়া অন্য ফাইল পাঠালে বা ২৫MB-এর বেশি হলে ৪০০ আসে; রিলস হিসেবে ছবি পাবলিশ করতে গেলে “রিলস হিসেবে শুধু ভিডিও প্রকাশ করা যায়”।

## ঙ) সম্প্রদায় ও শনাক্তকরণ (§১৬)

**১৩. মন্তব্য**
- যেকোনো পোস্টে মন্তব্য → সাথে সাথে তালিকায় দেখা যায়; অ্যাডমিন/এডিটর মুছতে পারে।

**১৪. “পরিচয় জানতে চাই”**
- `/share`-এ চেকবক্স টিক দিয়ে পোস্ট করলে পোস্টে “পরিচয় জানতে চাই — সাহায্য করুন” চিপ দেখা যায়।

**১৫. সম্প্রদায় প্রস্তাব যাচাইকৃত হয় না**
- মন্তবে প্রজাতির নাম দিয়ে পাঠালে ব্যাজ: “সম্প্রদায়ের প্রস্তাব — যাচাই হয়নি”।
- `PATCH /api/comments/<id> {verify:true}` অতিথি/সাধারণ ইউজার দিয়ে করলে **৪০১**।

**১৬. বিশেষজ্ঞ যাচাই**
- অ্যাডমিন/এডিটর `verify:true` পাঠালে ব্যাজ “বিশেষজ্ঞ-যাচাইকৃত”, পোস্টে `identifiedSpecies` সেট হয় ও লেখককে বিজ্ঞপ্তি যায়।

**১৭. রিপোর্ট**
- পোস্টের রিপোর্ট বাটন → কারণ নির্বাচন → `/admin/reports`-এ দেখা যায়; অবস্থা পরিবর্তন কেবল অ্যাডমিন/এডিটর করতে পারে।

## চ) এআই (§৯)

**১৮. সূত্রসহ উত্তর**
- `/ai`-তে “দোয়েল কী খায়?” → উত্তরের নিচে সূত্রের তালিকা ও প্রজাতির লিংক।

**১৯. না জানলে বাধ্যতামূলক বার্তা**
- সম্পূর্কহীন প্রশ্নে উত্তরে থাকবে: “আমার কাছে এই প্রশ্নের নিশ্চিত উত্তর নেই — আরও যাচাই প্রয়োজন। আমি অনুমান করে কোনো উত্তর তৈরি করব না।”

**২০. এসকেলেশন ও ট্র্যাকিং কোড**
- “বিশেষজ্ঞের কাছে পাঠান” → ট্র্যাক কোড পাওয়া যায় → `/ai/q/<code>` পেজে অবস্থা দেখা যায়; এই পেজ `robots: noindex`।

**২১. অ্যাডমিন উত্তর প্রকাশ**
- `/admin/ai` → ৭টি অবস্থা (নতুন/পর্যালোচনায়/অতিরিক্ত তথ্য/প্রক্রিয়াধীন/প্রকাশিত/সমাধান/সরানো); উত্তর লিখে প্রকাশ করলে ট্র্যাকিং পেজে দেখা যায়; “জ্ঞানভান্ডারে পরামর্শ” টিক দিলে পরামর্শ জমা পড়ে।

## ছ) অ্যাডমিন ও তথ্য ব্যবস্থাপনা (§১৭–§১৮)

**২২. কভারেজ ড্যাশবোর্ড**
- `/admin/coverage` ও `/api/coverage` → প্রতি দলে মোট/যাচাইকৃত/আংশিক/নামহীন/ছবিহীন/সূত্রহীন রেকর্ড; সংখ্যা সব ডেটাবেজ থেকে।

**২৩. CSV/JSON আমদানি-রপ্তানি + ডুপ্লিকেট**
- রপ্তানি: `/api/admin/species/export?format=csv` (বা `json`) — কেবল অ্যাডমিন/এডিটর; অন্যথায় ৪০১।
- আমদানি: `/admin/species`-এর “আমদানি” → CSV; বিদ্যমান নাম/স্লাগ/বৈজ্ঞানিক নাম থাকলে **ডুপ্লিকেট** হিসেবে এড়িয়ে যায় ও তালিকা দেখায়; “হালনাগাদের অনুমতি” দিলে আপডেট হয়।
- আমদানিতে কোনো রেকর্ডই স্বয়ংক্রিয়ভাবে `verified` হয় না।

**২৪. ভূমিকা ও অনুমতি**
- Guest · User · Verified Partner · Editor · Admin · Super Admin; সার্ভার-পাশে যাচাই — অ্যাডমিন রুটে সাধারণ ইউজারের ৪০১/৪০৩।
- পার্টনার (নীল টিক) কোনো অ্যাডমিন ক্ষমতা পায় না।

**২৫. অডিট লগ**
- নীল টিক, ভূমিকা পরিবর্তনসহ গুরুত্বপূর্ণ কাজের রেকর্ড `audit_logs`-এ পড়ে।

## জ) ব্যবহারকারী অভিজ্ঞতা (§১০, §২০)

**২৬. থিম/ভাষা/ডেটা-সেভার**
- `/settings` → লাইট/ডার্ক/সিস্টেম সাথে সাথে পুরো সাইটে প্রযোজ্য; রিফ্রেশ পরেও থাকে; ভাষা বাংলা↔ইংরেজি; ডেটা-সেভার, অটোপ্লে বন্ধ, সাউন্ড, কম অ্যানিমেশন কাজ করে।

**২৭. রেট লিমিটিং**
- এক মিনিটে ২০টির বেশি লেখার রিকোয়েস্ট বা ৫ মিনিটে ১০টির বেশি লগইন চেষ্টা করলে **৪২৯** + `retry-after` হেডার।

## স্বয়ংক্রিয় পরীক্ষা

```bash
npm run test:unit       # Vitest — কভারেজের হিসাব, রেট-লিমিট, ক্যাটাগরি/সংখ্যা/তারিখ
npm run test:contract   # ছবি, ক্রেডিট-রেজিস্টার, ভিডিও, SmartImage ফলব্যাক
npm test                # দুটোই
npm run lint            # ESLint
./node_modules/.bin/tsc --noEmit
```

কভারেজ টেস্টের মূল দাবি: **প্রাণীজগৎ ছাতা-রো মোটে গোনা হয় না** (নইলে ১৪৫১-এর জায়গায় ২৬৫৩ দেখায়)
এবং স্থান/সাহিত্যের অপ্রযোজ্য ক্ষেত্র ফাঁক হিসেবে গোনা হয় না।

## দ্রুত স্মোক টেস্ট (কপি-পেস্ট)

```bash
B=http://localhost:3000

# জনপ্রিয় / ক্যাটাগরি ফিল্টার
curl "$B/api/feed?sort=popular&limit=3"
curl "$B/api/feed?group=pakhi&limit=3"

# কভারেজ — rows + প্রকৃত totals (ছাতা-রো মোটে ধরা হয় না)
curl "$B/api/coverage"

# অতিথি পোস্ট (pending হওয়া উচিত)
curl -c /tmp/g.txt "$B/api/posts?limit=1" -o /dev/null
curl -b /tmp/g.txt -X POST "$B/api/posts" -H 'content-type: application/json' \
  -d '{"kind":"note","group":"pakhi","title":"পরীক্ষা","body":"পরীক্ষা","authorName":"রাহাত"}'

# মন্তব্যে প্রজাতির প্রস্তাব
curl -b /tmp/g.txt -X POST "$B/api/posts/<postId>/comments" -H 'content-type: application/json' \
  -d '{"body":"এটি দোয়েল","name":"করিম","suggestedName":"দোয়েল"}'

# রেট লিমিটিং
for i in $(seq 1 13); do curl -s -o /dev/null -w "%{http_code} " -X POST "$B/api/auth/login" \
  -H 'content-type: application/json' -d '{"username":"x","password":"y"}'; done   # শেষগুলো 429
```
