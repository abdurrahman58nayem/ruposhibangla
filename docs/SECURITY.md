# 🔐 নিরাপত্তা ও গোপনীয়তা — রূপসী বাংলা (§২০)

## ১. প্রমাণীকরণ ও সেশন

- পাসওয়ার্ড **কখনোই প্লেইন-টেক্সটে রাখা হয় না** — `lib/auth.ts`-এ সল্টেড SHA-256 (দ্বি-স্তর) হ্যাশ ব্যবহৃত হয়; প্রোডাকশনে bcrypt/argon2-এ স্থানান্তর করার পরিকল্পনা রয়েছে।
- সেশন কুকি `pb_session` — HMAC-সাইন করা (`AUTH_SECRET`), `httpOnly`, `sameSite=lax`, `secure` (প্রোডাকশনে)।
- `AUTH_SECRET` ছাড়া ডেভ মোডে একটি ডিফল্ট সিক্রেট থাকে — **প্রোডাকশনে অবশ্যই পরিবর্তন করতে হবে**।
- অতিথি শনাক্তকরণ: `middleware.ts` `pb_guest` কুকি সেট করে (অ-সংবেদনশীল, শুধু লাইক/রিপোর্ট/পোস্টের মালিকানা বোঝাতে)।
- **প্রথম নিবন্ধিত ব্যবহারকারী স্বয়ংক্রিয়ভাবে অ্যাডমিন** — সেটআপের পর অবশ্যই `/admin`-এ গিয়ে অন্য কাউকে Super Admin দিয়ে এই সুবিধা বন্ধ করতে হবে।

## ২. অনুমোদন (Authorization)

- প্রতিটি অ্যাডমিন রুট `/admin/layout.tsx`-এ **সার্ভার-পাশে** রোল যাচাই করে (`admin`/`super_admin`/`editor`)।
- প্রতিটি লেখার API (`/api/species`, `/api/news`, `/api/posts/[id]` ইত্যাদি) নিজেই সেশন ও রোল যাচাই করে — UI লুকিয়ে রাখলেই যথেষ্ট নয়।
- **Verified Partner (নীল টিক) কোনো অ্যাডমিন ক্ষমতা দেয় না।**
- অডিট লগ: নীল টিক, ভূমিকা পরিবর্তন, এআই প্রশ্নের উত্তর প্রকাশ, পোস্ট/মন্তব্য মুছা — `audit_logs`-এ সংরক্ষিত।

## ৩. ইনজেকশন ও ইনপুট যাচাই

- ডেটাবেজ অ্যাক্সেস **প্যারামিটারাইজড** (`@neondatabase/serverless` ট্যাগযুক্ত টেমপ্লেট) — স্ট্রিং কনক্যাটেনেশনে SQL তৈরি করা হয় না।
- সব ইনপুট **zod** দিয়ে যাচাই (দৈর্ঘ্য, এনাম, সর্বোচ্চ সীমা)।
- React স্বয়ংক্রিয়ভাবে এস্কেপ করে; `dangerouslySetInnerHTML` কেবল JSON-LD-তে ব্যবহৃত হয়।
- আপলোড: ধরন (`image/*`, `video/*`), সর্বোচ্চ ২৫MB, সার্ভার-সাইড যাচাই; ফাইল নাম `uid()` দিয়ে পুনর্লিখন।

## ৪. রেট লিমিটিং

`lib/rate-limit.ts` — ইন-মেমোরি স্লাইডিং-জানালা লিমিটার:

| স্কোপ | জানালা | সর্বোচ্চ |
|---|---|---|
| লেখা (পোস্ট/মন্তব্য/রিপোর্ট/পর্যবেক্ষণ) | ৬০ সেকেন্ড | ২০ |
| এআই প্রশ্ন | ৬০ সেকেন্ড | ১২ |
| আপলোড | ৬০ সেকেন্ড | ১৫ |
| লগইন/রেজিস্ট্রেশন | ৫ মিনিট | ১০ |

অতিক্রম করলে **HTTP ৪২৯** + `Retry-After`, `X-RateLimit-*` হেডার।

> ⚠️ সীমাবদ্ধতা: ইন-মেমোরি হওয়ায় একাধিক ইনস্ট্যান্স/সার্ভারলেস রিজিয়নে হিসাব ভাগ হয়ে যায় — বড় স্কেলে Redis/Upstash ব্যবহার করতে হবে।

## ৫. সংবেদনশীল প্রজাতি ও অবস্থান

- প্রজাতিতে `sensitive: true` দিলে সেই প্রজাতির পর্যবেক্ষণে **অবস্থান সংরক্ষিত হয় না** (`/api/observations`), এবং প্রজাতির পাতায় সতর্কতা দেখানো হয়।
- পর্যবেক্ষণ ফর্মে অবস্থান **ডিফল্টরূপে বন্ধ** — ব্যবহারকারী টিক দিলেই তথ্য যায়।

## ৬. এআই-তে পাঠানো ছবি কীভাবে প্রক্রিয়া হয়

1. ছবি `/api/upload`-এ যায় → R2 (বা লোকাল `public/uploads`) → ছবির URL ফেরত আসে।
2. `/api/ai`-তে URL বা রঙ-প্যালেট যায়। **লোকাল মোডে (ডিফল্ট) ছবি কোথাও পাঠানো হয় না** — ব্রাউজারেই রঙ বের করে সাইটের নিজস্ব তথ্যের সাথে মেলানো হয়।
3. `AI_PROVIDER=openai|openrouter|gemini` সেট করলে ছবি সেই প্রোভাইডারের ভিশন মডেলে যায় — তখন প্রোভাইডারের নিজস্ব নীতি প্রযোজ্য (গোপনীয়তা পেজে এই তথ্য খুলে বলা আছে)।
4. প্রশ্ন ও প্রসঙ্গ ইতিহাস `ai_questions`-এ সংরক্ষিত হয়; অ্যাডমিন ছাড়া কেউ দেখতে পায় না; ট্র্যাকিং পেজ `noindex`।
5. **এআই কখনো সরাসরি জ্ঞানভান্ডারে তথ্য লেখে না** — কেবল পরামর্শ জমা দেয়, অ্যাডমিন অনুমোদন করলে তবেই যায়।

## ৭. গোপনীয়তা

- অ্যাকাউন্ট ছাড়াই শেয়ার করা যায়; তখন শুধু দেওয়া নাম প্রকাশিত হয়।
- নিজের ডেটা ডাউনলোড ও অ্যাকাউন্ট মুছার অনুরোধ `/settings`-এ (ব্যাকগ্রাউন্ড জব বাকি — README দেখুন)।
- কুকি: `pb_session` (প্রমাণীকরণ), `pb_guest` (অতিথি শনাক্তকরণ), `pb_theme`/`pb_lang`/… (পছন্দসমূহ)।
- বিস্তারিত: `/privacy`।
